RPS Packet Steering Configuration

💡 What is RPS Packet Steering?
Receive Packet Steering (RPS) distributes incoming network packets to multiple CPU cores. Enabling it on network interfaces (e.g. wlan0 for hotspot, rmnet_data for mobile data) prevents CPU Core 0 bottlenecks, reducing ping spikes in online games when your hotspot is active.
Bitmask Guide: 0F = Core 0-3 (Efficiency) | F0 = Core 4-7 (Performance) | FF = All Cores (Max performance) | 00 = Disabled.
